## 👨‍💼 About Me

I'm a **financial data professional with 5+ years** of experience in alternative investment research — covering private equity, venture capital, M&A, hedge funds, and real assets across **APAC, EMEA, and Americas**.

What makes me different: I don't just do the job — I build tools that make the job better. From a **self-built Excel KPI tracker** for a 20-person team, to **AI-assisted workflows** using Claude that cut transaction processing time significantly, I find ways to work smarter at every level.

I'm currently expanding into **data analytics**, building SQL and Python portfolio projects alongside my day-to-day work at SourceScrub (part of Grata).

> *"I don't just work with data — I build the tools that make the data work."*
